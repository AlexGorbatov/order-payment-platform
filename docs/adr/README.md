# Architecture Decision Records

Decisions that shape the platform, with the alternatives that were rejected and why ([ADR-0001](0001-record-architecture-decisions.md)
explains the format). [architecture.md](../architecture.md) is the design; these records are the reasoning. All fourteen
remain **Accepted** following the 2026-10-09 implementation review. Acceptance records the chosen approach; it does not imply that every design goal is a shipped guarantee. Retention, HTTP crash recovery and observability limits are explicit in [architecture §17](../architecture.md#17-out-of-scope--future-work). Some carry an addendum with details that only the implementation
could settle.
